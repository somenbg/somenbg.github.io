Distributed GPU machine learning platform

Engineering distributed ML infrastructure on AWS EKS with Ray and KubeRay for model training, data processing, and GPU-accelerated inference.

Implemented and optimized · platform still evolving

Problem

Experimental training and inference needed to run as shared, repeatable workloads: multiple GPU types, datasets that do not fit a single machine, and a cost target tighter than “add more instances.”

Architecture

  • Amazon EKS for Kubernetes orchestration.
  • KubeRay for Ray cluster lifecycle.
  • Ray Train for distributed training, with TorchTrainer.
  • Ray Data, PyArrow, and S3 for distributed processing and feature paths.
  • PyTorch Distributed Data Parallel for multi-GPU training.
  • NVIDIA GPU instances, including A100 and H100 accelerators.
  • Amazon S3 for datasets and model artifacts, with IAM for workload access.

Challenges

  • Allocating GPU resources without wasting memory or leaving accelerators idle.
  • Distributed training across nodes.
  • Large datasets, and inference cost that had to beat a CPU baseline.
  • Workload concurrency, throughput, and the balance of performance, reliability, and spend.

Decisions

  • Cluster lifecycle stays in KubeRay rather than in ad-hoc process management.
  • Training uses Ray Train and PyTorch DDP so multi-GPU jobs have one execution model.
  • Data processing stays on Ray Data next to the training stack, instead of a separate handoff for every job.
  • Instance choice follows measured GPU memory and utilization, including spot capacity and autoscaling where the workload can tolerate it.

Results

  • Distributed GPU training supported with Ray and PyTorch.
  • GPU batch inference approximately 2–3× faster than CPU-based execution.
  • Inference compute cost approximately one-half to one-third of the CPU baseline.

These are results from this workload, not a general claim about every GPU job.

Takeaway

The cost and speed results arrived after data placement, batch shape, and accelerator memory were designed together. A larger cluster alone did not produce them.
